# 2gether

Веб-приложение для совместной жизни пары: общий бюджет, задачи, вишлист, фотоальбом, настроение и календарь встреч.

Курсовая работа по ООП, МГТУ «СТАНКИН», 2026.

## Стек

- **Backend:** Python 3, Flask, Flask-Login, SQLAlchemy, PostgreSQL
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **C++:** ctypes-мост для алгоритмов поиска свободного времени и подсчёта баллов
- **Deploy:** Railway, GitHub

## Возможности

- Регистрация и вход, связывание аккаунтов по инвайт-коду или QR
- Общий кошелёк с категориями и статистикой
- Копилки на общие цели с прогресс-баром
- Календарь занятости и поиск свободных окон для встреч
- Домашние дела с баллами и недельным рейтингом
- Ежедневное настроение и календарь за 28 дней
- Вишлисты с приоритетами и ценами
- Совместный фотоальбом
